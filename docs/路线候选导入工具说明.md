# 路线候选导入工具

Map Resource Library Phase 2 现在支持将路线规划器输出写入 `route_candidates`。
该步骤只记录静态候选路线，不代表 CARLA 穿越验证，也不代表重型矿卡安全验证。

## 输入格式

输入可以是 JSON 数组，也可以是包含 `route_candidates` 数组的对象：

```json
{
  "route_candidates": [
    {
      "route_candidate_id": "s07-a-r1",
      "map_id": "0325_5",
      "resource_version": "1.0-draft",
      "from_point_id": "start-point-id",
      "to_point_id": "target-point-id",
      "candidate_rank": 1,
      "planner_version": "CARLA_GlobalRoutePlanner",
      "route_hash": "sha256-or-planner-hash",
      "road_lane_sequence": {"edge_ids": ["R1", "R2"]},
      "validation_status": "CANDIDATE",
      "source": "CARLA_CALIBRATION_PENDING"
    }
  ]
}
```

起点和终点必须已经存在于 `map_points`，否则 SQLite 外键会拒绝写入。

## 导入命令

```bash
cd open_pit_agent_demo
python scripts/import_route_candidates.py route_candidates.json \
  --database data/database/map_resources.db
```

也可以用命令行统一覆盖输入文件中的地图和资源版本：

```bash
python scripts/import_route_candidates.py route_candidates.json \
  --map-id 0325_5 --resource-version 1.0-draft
```

同一个 `route_candidate_id` 重复导入是幂等的。
