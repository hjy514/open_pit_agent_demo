## 三、程序提交包必须包含什么

### A. 必须提交的源代码

提交 Git 仓库中以下内容：

- `src/`：Agent、风险、调度、场景、CARLA 适配、数据库和闭环代码；
- `open_pit_dispatch_app/`：PyQt6 调度中心；
- `scripts/`：统一场景、地图资源、数据导出和验收工具；
- `configs/`：场景、监测、风险、代价和地图资源配置；
- `tests/`：自动回归测试；
- `run_scenario.sh`、`run_demo.py`、`start_carla.sh`、`start_api.sh`、`start_dispatch_app.sh`、`start_slope_demo.sh`、`check_environment.sh`、`map_resources.sh`；
- `requirements.txt`、`open_pit_dispatch_app/requirements.txt`、`README.md` 和 `docs/`。

### B. 必须作为运行附件提供的内容

这些内容不适合直接放进 Git，但运行 CARLA 版项目时必须一并交付：

- CARLA 0.9.10 运行包；
- `0325_5` 地图包，例如 `0325_5_0.9.10-dirty.tar.gz`；
- `vehicle.cat.cat` 矿卡蓝图所在的 CARLA 内容包；
- 已完成 P3/P4/P5/P6 资源记录的 `data/database/map_resources.db`（当前约 14 MB）；
- 一份脱敏、可选的 `openpit.db` 示例数据库，或让程序首次运行自动创建空库；
- 选定的成功运行证据目录，而不是全部 891 MB 的本地 `artifacts/`。
- 如材料提到离线学习候选，还应单独提供 `data/models/dispatch_policy/` 中选定版本的 `model.json`、`training_report.json` 以及对应数据集 `manifest.json`；材料中建议将其定位为 Shadow/离线候选，并说明后续的模型增强路径。

注意：当前 `.gitignore` 忽略 `data/database/`，所以 `git push` 不会上传两个数据库。只提交源代码而不提供 `map_resources.db`，六车场景的地图资源准入可能无法运行。

### C. 不要提交的内容

- `.git/`、`__pycache__/`、`*.pyc`；
- 全量 `artifacts/`、运行日志和摄像头帧；
- 个人绝对路径配置、个人 Conda 环境和本机缓存；
- `dashboard_redesign_current.txt`、`old_camera_source.tar.gz`、`old_dashboard_reference.tar.gz`；
- CARLA 安装目录内部的临时文件和崩溃转储。
