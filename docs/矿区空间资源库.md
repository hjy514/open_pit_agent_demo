# 矿区空间资源库

## 定位

`data/database/map_resources.db` 是 `0325_5` 的静态地图事实库。它不保存某一次运行的天气、拥堵、道路关闭或风险状态；这些运行事实必须进入 `openpit.db`。

## 已保存的资源类型

- 地图版本、CARLA Spawn Point、点位角色和作业区；
- 路网节点、道路边、路口连接与道路簇；
- 静态点对冲突候选；
- P5 GlobalRoutePlanner 可达性和路线候选；
- P6 `vehicle.cat.cat` 单车物理路线验证；
- 安全等待点、任务点和风险锚定区。

## 验证等级

| 等级 | 含义 | 不代表什么 |
|---|---|---|
| P3 | 单矿卡可在 Spawn Point 生成 | 不代表路线、会车或碰撞安全 |
| P4 | 静态距离推断的冲突候选 | 不代表真实物理碰撞 |
| P5 | GlobalRoutePlanner 可以生成路线 | 不代表矿卡实际能跑通 |
| P6 | `vehicle.cat.cat` 单车到达目标容差内 | 不代表多车会车、净空、碰撞或交通安全 |

当前已记录 82 个 Spawn Point、118 个路网节点、130 条拓扑边。P6 状态同时保留 `PHYSICAL_REACHED` 和 `PHYSICAL_STUCK`，失败样本是规划与准入的重要事实，不能删除或改写为成功。

## 常用命令

```bash
./check_environment.sh --require-target-map
./map_resources.sh build-db
./map_resources.sh import-topology
./map_resources.sh validate-reachability --pair-limit 250
./map_resources.sh validate-physical --auto-candidates 12 --seed 202617 \
  --minimum-route-length-m 100 --maximum-route-length-m 500
./map_resources.sh coverage
```

物理验证前必须确认 CARLA 当前地图为 `0325_5`。工具不会自动切换地图，以避免在错误地图上写入验证结论。

## 使用原则

- P5 与 P6 严格分开；
- CARLA 多车物理场景优先只从 P6 成功路线中采样；
- 地图事实只写入 `map_resources.db`，运行中的道路状态和风险写入 `openpit.db`；
- 资源不足时 Episode 生成必须拒绝运行，而不是伪造或降级物理结论。
