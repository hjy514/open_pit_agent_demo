# 里程碑08：作业态势地图与风险趋势

日期：2026-08-01

## 1. 本阶段目标

将原有按车辆坐标自动缩放的代理分布图升级为统一坐标态势图：

```text
CARLA Town03车道中心线
          +
任务区域与风险区域
          +
车辆当前位置与历史轨迹
          +
道路限制和风险趋势
          ↓
      浏览器态势图
```

## 2. 地图接口

接口：

```text
GET /api/map
```

服务从CARLA读取 `generate_waypoints(5.0)`，按照：

- `road_id`；
- `section_id`；
- `lane_id`

分组并按道路里程 `s` 排序，输出车道中心折线。

Town03当前结果：

| 字段 | 结果 |
|---|---:|
| 坐标系 | `carla_local_meters` |
| 采样距离 | 5 m |
| 车道折线 | 341条 |

地图首次读取后缓存在可视化服务内存中，不会在每秒页面刷新时重复连接CARLA。

## 3. 新增运行证据

每次CARLA运行现在记录 `runtime_scene`：

- 地图名称；
- 任务区域ID和名称；
- 区域CARLA坐标；
- 目标出生点编号；
- 能力要求和优先级。

`task_started` 事件新增目标坐标。每20 tick记录的车辆位置同时投影为车辆轨迹，状态接口最多保留每辆车最近240个采样点。

## 4. 页面图层

从下到上依次显示：

1. Town03车道中心线；
2. 三辆车的历史轨迹；
3. 常规巡检区、风险区、管控点和应急点；
4. 当前车辆位置和业务ID。

活动道路限制关联的风险区域使用红色标记。当前限制仍然是策略层限制，地图显示不能代替真实路网边级绕行。

风险趋势图按tick显示蓝、黄、橙、红评估节点，触发原因继续显示在风险详情中。

## 6. 对矿山迁移的影响

前端只依赖：

- 地图折线；
- 地图边界；
- 区域坐标；
- 车辆坐标与轨迹；
- 区域或路段限制ID。

换成矿山地图时，可由矿区OpenDRIVE、GIS路网或自定义调度图输出相同结构。需要额外处理：

- 矿区坐标系与CARLA/世界坐标转换；
- 道路宽度、坡度、限速和路权；
- 真实禁行道路边，而不只是区域标记；
- 轨迹偏离、会车冲突和制动距离可视化。
