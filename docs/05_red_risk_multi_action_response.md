# 里程碑05：红色风险多装备联动处置

日期：2026-08-01

## 1. 本阶段目标

在橙色风险复核和工单闭环基础上，将红色风险扩展为多动作联动：

```text
固定站 + 移动装备合成观测
             ↓
      蓝 → 黄 → 橙 → 红
             ↓
  ┌──────────┼──────────┐
风险复核   道路管控   应急响应
  ↓           ↓           ↓
融合巡检车     应急执行车任务队列
  └──────────┬──────────┘
         独立工单闭环
```

该阶段验证的是普通车辆代理环境中的软件功能链，不是露天矿工业验证。

## 2. 为什么拆成三个动作

同一个红色风险不能只表现为“再去巡检一次”。比赛方案需要体现风险出现后系统能够：

- 派感知装备复核风险；
- 将风险区登记为受控区域，阻止普通任务进入；
- 派应急装备执行道路管控；
- 派应急装备继续执行响应任务；
- 分别记录每项动作的车辆、状态、完成时间和工单结果。

每个动作有独立的 `task_type`、能力要求、优先级、工单类型和复核延迟。同一次风险事件可关联多张工单，工单ID使用关联任务ID确保不冲突。

## 3. 策略层道路限制

红色风险在 tick 120 激活：

```text
road_segment_id: town03_proxy_risk_segment_02
zone_id: risk_zone_02
allowed_task_types:
  - risk_review
  - road_control
  - emergency_response
```

活动限制会取消进入该区域的普通任务，同时允许风险复核和应急处置任务进入。

本阶段摘要明确输出：

```text
route_avoidance_enforced: false
restriction_scope: policy_layer_only_town03_proxy
```

这表示当前尚未修改 CARLA 全局路径规划图，也没有证明车辆会绕过任意封闭道路边。矿山地图阶段必须把 `road_segment_id` 映射到真实道路拓扑边，再由路径规划器执行禁行和重规划。

## 4. 路线链校准

抢占场景不能只检查“车辆出生点→任务目标”，还要检查“风险目标→恢复任务目标”。

路线工具新增：

```bash
--origin-spawn-point-index
```

它可以从任意中间点校准后续路径。本场景最终选择：

- 融合巡检车出生点122到常规点85：约88.07 m；
- 风险点136到恢复常规点85：约27.09 m；
- 应急车出生点0到道路管控点218：约32.93 m；
- 路线终点误差均低于8 m到达容差。

该修正避免了只按初始路径选点导致恢复任务绕行过长。

## 5. 正式 CARLA 结果

复现命令：

```bash
cd /home/hjy/open_pit_agent_demo
/home/hjy/miniconda3/envs/tcp37/bin/python run_demo.py \
  --config configs/town03_red_response.json \
  --risk-config configs/risk_slope_red_synthetic.json \
  --mode carla-run \
  --load-map \
  --spawn-missing \
  --ticks 3000
```

`--load-map` 必须用于正式重复验收，以清除上次运行遗留的同名车辆位置；`--spawn-missing` 再按当前配置生成三辆代理车辆。

## 6. 失败结果为什么保留

开发过程中保留了两个诊断结果：

- 未加载地图时复用了旧车辆位置，导致3000 tick运行仍未完成；
- 初版恢复目标231只校准了初始路线，风险点出发的恢复路径过长并超时。

这些结果说明正式演示需要场景复位和完整路径链校准。它们不作为通过证据，但对以后矿山长路段、单行道路和动态封控测试有直接参考价值。

## 7. 迁移到矿山环境时保留与替换

可直接保留：

- 风险等级和动作触发接口；
- 多动作任务模型；
- 能力约束和任务优先级；
- 抢占、排队与恢复；
- 多工单状态机；
- 道路限制登记和授权任务规则；
- 事件日志、指标和验收摘要。

必须替换或新增：

- Town03地图和普通车辆蓝图；
- 合成观测、演示阈值和自动复核；
- 真实矿区道路拓扑及路段ID；
- 路段关闭、绕行、路权和动态重规划；
- 真实固定监测站、无人装备传感器和数据时钟；
- 人工审批、告警通知和持久化平台。
