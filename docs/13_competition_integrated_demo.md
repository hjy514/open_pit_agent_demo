# 里程碑13：比赛一键综合演示

日期：2026-08-01

## 1. 目标

将此前分开验收的故障接管和边坡风险处置合并为一次可录屏、可截图、可生成测试报告证据的运行。

控制场景：

```text
competition_demo
```

## 2. 完整事件链

1. 保存自然语言任务；
2. 输出白名单基线结构化意图，并明确未使用大语言模型；
3. 感知巡检车执行常规任务；
4. 固定种子在tick 120注入车辆故障；
5. 通过`fault_recovery`能力将任务交给应急车；
6. 合成数据在tick 0/220/360/520形成蓝/黄/橙/红风险；
7. 融合巡检车执行橙色和红色复核；
8. 应急车执行道路管控和应急响应；
9. 4张工单完成待处理、派发、执行、复核和关闭；
10. 普通常规任务恢复并完成。

## 3. 多车协同问题与修复

组合测试发现：车辆完成任务后停在共享车道，会触发CARLA BasicAgent车辆避障，使后续应急车辆停止。

新增规则：

```text
至少完成过一项任务
+ 当前任务队列为空
→ 横向进入路侧待命位
→ 记录vehicle_parked_off_route
```

初始待命车辆不执行横移。该边界由两项独立单元测试覆盖。

该规则是Town03代理场景中的最小共享车道释放机制。矿山阶段应替换为真实停车区、会车点、路权和时空冲突消解模型。

- 风险数据和阈值为合成Demo数据；
