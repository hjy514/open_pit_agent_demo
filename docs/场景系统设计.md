# 场景系统设计

## 场景与 Episode

场景是逻辑规则，Episode 是一次确定实验输入：

```text
ConcreteEpisode = Generator(ScenarioTemplate, MapResources, VehicleCount, Seed)
```

同一场景、同一车辆数、同一 Seed 和同一地图资源版本必须生成相同 Episode。Episode 在执行前应写入 `openpit.db`，以便复现和比较。

## 受约束随机规则

可随机的对象包括车辆数量、合法出生点、任务目标、角色、任务优先级、故障车辆、事件时间、道路边和天气参数；但所有随机必须由 Seed 驱动并受以下硬约束限制：

- 出生点必须来自可用资源池，且通过冲突过滤；
- 路线必须满足当前模式要求：结构化可使用 P5，物理 CARLA 必须使用 P6；
- 故障事件必须作用于正在执行的车辆；
- S02 必须存在能力匹配、可达的接管候选；
- S07 关闭的道路必须实际影响至少一条当前任务路线；
- 资源不够时必须 fail closed，不得暗中减少车辆数或放宽安全条件。

典型失败码：`INSUFFICIENT_VALID_SPAWNS`、`INSUFFICIENT_PHYSICAL_ROUTES`、`NO_VALID_TARGET`、`NO_VALID_EVENT`、`NO_TAKEOVER_CANDIDATE`、`RESOURCE_CONFLICT`。

## 场景执行边界

结构化模式验证事件、状态、决策、闭环和数据流，不宣称 CARLA 物理完成。CARLA 模式在运行前进行资源准入，执行结果由实际车辆反馈决定。S08 继续使用既有独立 Golden 流程。
