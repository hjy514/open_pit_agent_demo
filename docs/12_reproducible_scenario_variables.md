# 里程碑12：统一场景变量与可复现随机试验

日期：2026-08-01

## 1. 已落实内容

场景配置可以通过可选的 `scenario_variables` 集中描述：

- 环境：温度、风速、能见度、扬尘、道路附着和通信延迟；
- 灾害：类型、位置、阶段、是否激活和数据来源；
- 任务：自然语言指令、任务类型和成功条件；
- 随机事件：事件类型、概率、候选装备和发生tick范围。

旧配置不包含该字段时继续按原逻辑运行。

## 2. 受控随机

运行支持三种模式：

- 配置固定种子：比赛稳定演示；
- `--seed`：复现指定试验；
- `--randomize`：生成并保存新的试验种子。

`--seed` 和 `--randomize` 不能同时使用。

## 3. 证据

每次运行首先写入：

```text
scenario_snapshot.json
```

快照是本轮实际执行条件，不是未解析的范围配置。故障事件同时在 `events.jsonl` 中记录 `scenario_seed`，可以核对场景计划与实际执行是否一致。

CARLA回归证据：

```text
artifacts/runs/town03-fault-recovery-v1-20260801T120438Z-bbfb3215
```

固定种子 `202616` 解析出：

- 故障装备：`emergency_vehicle_01`；
- 故障发生：tick `81`；
- 实际故障事件：tick `81`；
- 结果：`PASS`，任务完成率100%。
