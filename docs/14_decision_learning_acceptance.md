# 决策智能、经验学习与自动验收

## 目标

本层把现有的“感知—风险评估—调度—执行—工单”闭环统一成可解释、可复现、可积累经验的比赛 Demo，同时保留从 Town03 普通车辆代理迁移到矿山地图和矿用装备的接口。

## 运行时链路

```text
场景文件与固定/随机种子
→ 环境、灾害、任务和故障变量
→ 透明风险评估
→ 影响、预防措施和规划动作
→ 能力/距离/负载约束调度
→ CARLA车辆执行
→ 任务与工单结果
→ 决策记录、经验样本、验收报告
```

智能体分工采用结构化软件 Agent，而不是声称已经调用大模型：

- `perception_agent`：汇总车辆状态、位置、能力和风险观测；
- `risk_assessment_agent`：根据显式阈值产生等级、依据、影响和预防措施；
- `scheduling_agent`：按能力、优先级、距离和负载选择车辆；
- `safety_execution_agent`：执行任务、道路限制、故障接管和终态驻车。

## 可训练性边界

每项任务结束后形成一条 `experience_dataset.jsonl` 样本，包含：

- 场景、种子、任务、能力要求和风险状态；
- 被选车辆与策略版本；
- 最终状态、尝试次数和起止 tick；
- 显式奖励公式；
- 是否可作为模仿学习样本。

当前没有训练神经网络模型，`model_trained=false`。系统会在后续运行读取同一场景过去的成功样本，按任务类型和车辆形成最大 `2m` 等效调度分值的有界模仿偏好。该偏好只能在已经通过能力、健康和安全筛选的车辆之间起作用，不能绕过硬约束，也不会自动修改风险阈值。

因此第一次 CARLA 综合运行主要建立经验；第二次及以后可以在 `imitation_memory_loaded` 事件和运行摘要中看到成功经验数与实际偏好。后续仍可在此基础上训练调度排序模型，并通过固定种子回放与透明基线做对照。

## 自动验收

`acceptance_report.json` 根据场景适用范围检查：

- 场景种子可复现；
- 多智能体决策可追溯；
- 全任务完成和车辆终态停止；
- 故障接管闭环；
- 动态风险评估及影响/预防解释；
- 风险任务、工单和红色道路限制；
- 经验数据完整导出。

报告同时保留五项边界：合成风险数据、未训练模型、策略层道路限制、普通车代理和真实部署需人工/合规验证。

## 迁移到矿山环境

保持本模块、调度接口、任务模型、工单和证据格式不变，替换：

- Town03地图与出生/目标点；
- 普通车辆蓝图与能力配置；
- 合成观测与演示阈值；
- 代理道路段与真实矿山路网边；
- 演示奖励与现场安全/效率指标。

因此本次实现不是一次性 Town03 页面效果，而是后续矿山环境的数据和决策骨架。
